01 / REAL-TIME VISION

ombrelle-live

人が動くと筆が傾ぎ、止まると絵が凪ぐ。

Webカメラ映像を、単眼深度とオプティカルフローで駆動する印象派表現へ変換するリアルタイム処理系。 深度を筆の大きさと空気遠近へ、動きを筆触の向きへ接続しています。

Pipeline
OpenCV → PyTorch/MPS → OpenGL/GLSL
Model
25.6× fewer parameters
Rendering
52.9 → 134.6 fps*

* 合成入力・計測環境上のA/B。実写への汎化性能は未検証。

02 / PHYSICAL RENDERING

sky-ocean-renderer

光の式から、空と海を描く。

レイリー散乱・ミー散乱・Beer–Lambert則をフラグメントシェーダ内で数値積分するWebGLレイトレーサー。 海面のフレネル反射、体積雲、太陽と月の昼夜変化を同じ光のモデルにつないでいます。

Core
GLSL / WebGL
Method
