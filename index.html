作品

ombrelle-live

Webカメラ映像を、単眼深度とオプティカルフローで駆動する印象派表現へ変換するリアルタイム処理系です。深度を筆の大きさと空気遠近へ、動きを筆触の向きへ接続しています。

使用技術
Python / PyTorch / OpenCV / OpenGL / GLSL
実装のポイント
単眼深度を筆の大きさと空気遠近へ、オプティカルフローを筆触の向きへ対応づけ、映像の変化を描画へ反映。

sky-ocean-renderer

レイリー散乱・ミー散乱・Beer–Lambert則をフラグメントシェーダ内で数値積分するWebGLレイトレーサーです。海面のフレネル反射、体積雲、太陽と月の昼夜変化を同じ光のモデルにつないでいます。

使用技術
WebGL / GLSL / Ray Marching
実装のポイント
大気散乱をフラグメントシェーダ内で数値積分し、空・海面反射・体積雲・昼夜変化を同じ光のモデルへ統合。

経験と技術

教育事業者向け業務システム

2024年から、オンライン個別指導事業で生徒・講師・運営者が利用するWebシステムの要件整理、設計、実装、テスト、運用を担当しています。スプレッドシート、GAS、連絡ツールに分散していた授業予定、振替、勤怠、通知、履歴を、一つの業務フローとして再設計しました。

現場へのヒアリングとユーザーテストを通じて、要望を画面・状態遷移・データモデルへ変換しています。システム化した一部の定型業務では、確認・入力・集計・連絡に要する時間を従来比で10分の1以下に削減しました。

初期版の運用で見えた保守性とテスト容易性の課題を踏まえ、現在は機能単位の構成、型付きAPI契約、業務ロジックとDB・外部連携の分離、段階的なデータ移行を含む再設計にも取り組んでいます。
