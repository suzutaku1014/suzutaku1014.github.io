このサイトについて

現実とデジタルのあいだに、
人の知覚へ届く体験をつくる。

このサイトは、鈴木拓海の制作と関心領域をまとめたポートフォリオです。完成物だけでなく、何を考え、どの原理を調べ、どう実装へ落とし込んだかが伝わるように構成しています。

現在は、現実の映像や動き、奥行き、光を計算可能な形で捉え、人の知覚や体験へ返す技術に関心を持ち、3Dグラフィックス、コンピュータビジョン、機械学習を学んでいます。

02

作品

ombrelle-live

Webカメラ映像を、単眼深度とオプティカルフローで駆動する印象派表現へ変換するリアルタイム処理系です。深度を筆の大きさと空気遠近へ、動きを筆触の向きへ接続しています。

領域
Real-time Visual Computing
技術
Python / PyTorch / OpenCV / OpenGL / GLSL
担当
企画・設計・実装・検証

sky-ocean-renderer

レイリー散乱・ミー散乱・Beer–Lambert則をフラグメントシェーダ内で数値積分するWebGLレイトレーサーです。海面のフレネル反射、体積雲、太陽と月の昼夜変化を同じ光のモデルにつないでいます。

領域
Physically Based Rendering
技術
WebGL / GLSL / Ray Marching
担当

プロフィール

Web開発で培った、曖昧な課題を分解して動くものへ落とし込む力を土台に、リアルタイム映像・空間表現の領域へ専門性を広げています。

  1. 2024

    Webシステム開発

    教育事業者向けシステムで、要件整理から運用まで一連の開発を担当。

  2. 2025 秋

    作りたい体験へ軸足を移す

    外から比較できる成果だけでなく、自分が価値を感じる対象へ深く向き合うことを選択基準にする。

  3. 2026

    Visual Computingを学ぶ

    ゲームエンジンを入口に、光学・レンダリング・画像認識・機械学習の原理と実装を学習。

    映像や空間情報にリアルタイムで応答し、人の見え方を変える技術を探究しています。
